## 待決問題

- **增量是架構要求，不是最佳化。** 打一個字重排整份文件是 `O(n)`，文件一大即失效。
  失效傳播的粒度是什麼？段落？行？run？
- **流式與空間如何共用同一份 node tree**：流式的位置是算出來的，空間的位置是存起來的。
  這是本專案最原創、也最容易走偏的問題。
- **display list 的格式**：連續緩衝區、零複製可讀、外殼不需要知道任何文件結構。
  版本化策略是什麼（核心與外殼可能不同步升級）？
- **一幀預算**：目標數字必須先定，否則「夠不夠快」沒有判準。
