（尚無）

## 待決問題

- **stable ID 的形式與生成**：識別必須在 rename、移動、內容變更後仍然穩定。
- **節點不得假設位置的來源**：同一份 tree 要同時支撐流式（位置算出來）與空間（位置存起來）版面。
  這個約束如何在型別上表達？
- **composing region 在文件模型中的位置**：暫定文字必須被版面看見，但不得進 undo stack。
  它是節點的屬性，還是與 tree 平行的疊加層？
- **schema 版本策略**：第一版即需決定「舊檔怎麼讀」，否則 P1.5 開始 dogfood 後的資料無法演進。
- **第一版 codec 是刻意可丟棄的**：P1.5 只需要能存檔以支撐 dogfood，正式格式待 `ATH-*`。
  這一點必須在決策裡寫明，否則會被誤當成正式格式沿用。
