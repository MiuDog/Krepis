## 範圍

persistence、identity、permission、protocol、event digest。out-of-process 執行。

## 什麼該放這裡

**「什麼是真相、誰有權改它、以及它怎麼存活」的決策。**

## 排序說明

**本能力刻意排在最後（P5）。**

排序原則是「先做會殺死架構的未知」。authority 是**已知可解**的工作量——同一組能力已在
既有專案以 C++ 實作過一次（74,016 行）。先做它意味著要花數月才會知道版面／FFI／IME
那條線成不成立，而那些才是會殺死架構的未知。

P1.5 的 dogfood 需求由**刻意可丟棄的簡陋檔案格式**支撐（見 `01-document`），
不是由本能力支撐。該格式在本能力落地時會被丟棄，**這一點必須寫在決策裡**，
否則會被誤當成正式格式沿用。
